# گزارش مرحله ۱: دستیار صوتی «هی جارویس»

- **شاخه:** `dev/jarvis-2` (هنوز در main ادغام نشده)
- **تاریخ:** ۲۴ آبان ۱۴۰۵

## چه ساخته شد

| بخش | فایل‌ها | چه می‌کند |
|---|---|---|
| کلاینت مستقیم LLM | `lib/llm.js` | چت استریم با APIهای سازگار با Anthropic و OpenAI. برای Claude بدون کلید API از Claude Code استفاده می‌کند. |
| بیدارباش | `public/voice/wakeword.js` | مدل `hey_jarvis` از openWakeWord با onnxruntime-web، داخل پنل و کاملاً محلی. «هی جارویس» فارسی: عبارت‌های کوتاه با گفتار به متن محلی (فقط محلی) بررسی می‌شوند. |
| گفتار به متن | `lib/voice/speech.js` | whisper.cpp به‌صورت سرور مقیم با مدل large-v3-turbo. نسخه‌ی CUDA برای کارت NVIDIA. یا API OpenAI. |
| متن به گفتار | `lib/voice/speech.js` | Piper محلی (فارسی: امیر/ژیرو، انگلیسی: Lessac) یا API OpenAI. |
| دانلود اجزا | `lib/voice/assets.js` | فقط با کلیک کاربر، با نمایش حجم و پیشرفت. منبع‌ها: انتشارهای رسمی GitHub و HuggingFace. |
| مغز صوتی | `lib/voice/brain.js` | جواب کوتاه و یک اقدام از فهرست ثابت: شروع کار تیمی، توقف، افزودن تسک، تمام کردن تسک، باز کردن بخش. «شروع کار تیمی» قبل از اجرا «بله» می‌خواهد. |
| تسک‌ها | `lib/tasks.js` | فهرست تسک‌ها (پایه‌ی بخش Tasks در مرحله‌ی بعد). |
| سرور | `server.js` | مسیرهای `/api/voice/*` و `/api/tasks`، و اجرای اقدام‌ها. |
| رابط | `public/voice/voice.js`، `public/ext.css`، `public/index.html` | دکمه‌ی میکروفون، نوار شناور صوتی با موج، دکمه‌های تأیید، پنجره‌ی تنظیمات صدا، میانبر Ctrl+Space. |

## حریم خصوصی و ایمنی

- تا بیدارباش یا کلید میانبر، هیچ صدایی ضبط یا جایی فرستاده نمی‌شود.
- تشخیص فارسی «جارویس» فقط از موتور محلی استفاده می‌کند؛ سرور این را اجبار می‌کند.
- اقدام‌ها به فهرست ثابت محدودند. نوع ناشناخته کنار گذاشته می‌شود.
- اقدام‌هایی که پروژه را تغییر می‌دهند تأیید می‌خواهند.

  - تسک ساخته شد و جواب به فارسی خوانده شد.

## محدودیت‌های شناخته‌شده

- **«هی جارویس» با تلفظ کاملاً فارسی:** مدل انگلیسی امتیاز پایین (۰٫۰۹) می‌دهد. برای همین از مسیر دوم استفاده می‌شود: گفتار به متن محلی و جستجوی «جارویس». روی CPU کندتر است؛ روی کارت گرافیک فوری است.
- **دقت با صدای ماشینی:** با صدای مصنوعی از میکروفون شبیه‌سازی‌شده، دقت تشخیص فارسی پایین بود: «تسک» شنیده شد «تصفیح» و «نان» شنیده شد «نام». **هنوز با صدای واقعی انسان تست نشده.**
- **سرعت جواب:** با Claude از طریق Claude Code حدود ۸ ثانیه طول می‌کشد. با کلید API یا یک اتصال سریع باید ۱ تا ۲ ثانیه شود. این هم تست نشده.
- **API گفتار:** گفتار با OpenAI فقط با سرور جعلی تست شده، نه با کلید واقعی.
- **انگلیسی:** صدای انگلیسی «Ryan» با Piper نسخه‌ی ۲۰۲۳ سازگار نبود و با «Lessac» جایگزین شد.
